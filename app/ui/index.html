Demo Walk-Through
1

Run Syncs

Go to Sync and click Run CRM Sync then Run Custodian Sync (or use the Run Full Demo Sync button above). Watch the log. The CRM connector pages through households and contacts, applies HMAC / Fernet encryption for PII. The custodian connector validates SHA-256 hashes, processes the supersedes chain so MC-20261008-02 correctly overrides MC-20261008-01.

2

Browse Households

Go to Households to see all 6 CRM households. Note Whitfield Family (H-1004) is soft-deleted. Account 4430 shows CLOSED in Oct-9. Account 4499 and 4460 are unlinked (no household association).

3

Query Context API — Agent vs Ops

Go to Context API. Select H-1001 Chen Family and toggle between agent and ops principals. Note: agent sees masked email r***@example.com, no phone. Ops sees plain email, last-4 phone. Neither ever receives tax_id. Finding detail appears only for ops.

4

Review Findings

Go to Findings. Key findings: POSSIBLE_DUPLICATE_PERSON for Robert Chen / Bob Chen (same HMAC, nickname match), UNLINKED_ACCOUNT for 4460 and 4499, DUPLICATE_POSITION for VTI in account 4401 Oct-8 v1 drop (effective snapshot corrects this).

5

Inspect Sync Runs

Go to Sync Runs to see every run — status, records ingested, checkpoint advanced, errors. A failed run does not advance the checkpoint. Previously ingested canonical data is always available.

Sync Control

CRM Sync ledgerline_crm

Syncs households, contacts, and account references from Ledgerline CRM. Uses cursor pagination with incremental checkpoint. Retries on 429/503.

Custodian Sync meridian_custody

Ingests CSV file drops from the custodian_drops/ folder. Validates SHA-256 hashes, row counts, resolves the supersedes chain to select effective snapshots.
